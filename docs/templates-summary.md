# Templates summary (from `template.pdf`, 25 pages)

The PDF has no text layer, so it was read page by page as images.
Sections 1–6 share one design: purple banner (section name + subtitle
"نموذج البيانات الرقمية للتقرير الأسبوعي والشهري"), a "هدف التقرير" box on page 1,
numbered cards (3 per page) and a page number "n / N" at the bottom.
Each card in the PDF is a bullet list of field names; those names became the form fields.
Repeating records (logs, requests, plans…) became tables with add/delete row.

## 1. المحتوى والإعلام
هدف: قياس الإنتاج الإعلامي، التغطية، الوصول، التفاعل، جودة المحتوى، والالتزام بالخطة الإعلامية.
1. بيانات التقرير (القسم، المسؤول، الفترة، البداية/النهاية، نوع التقرير ☐ أسبوعي ☐ شهري، تاريخ الإصدار، الحالة ☐ مسودة ☐ بانتظار المراجعة ☐ معتمد ☐ صادر)
2. سجل المحتوى المنفذ — *table* (عنوان، نوع ☐ منشور/ستوري/ريلز/فيديو/تصميم/خبر/مقابلة/إعلان/تغطية/حملة، منصة، تاريخ النشر، مسؤول، حالة، رابط المنشور، رابط ملف التصميم، ارتباط بمشروع/فعالية، اسم المشروع/الفعالية)
3. مؤشرات الإنتاج (8 أرقام) 4. مؤشرات الوصول والتفاعل — *table by platform* 5. التغطية الإعلامية — *table*
6. الجودة والالتزام 7. التحديات والاحتياجات — *table* 8. الخطة القادمة — *table* 9. مؤشرات التقرير النهائية

## 2. الإدارة اللوجستية
هدف: قياس جاهزية الموارد والتجهيزات، سرعة الاستجابة، المخزون، النقل، الصيانة، ودعم الفعاليات.
1. بيانات التقرير 2. طلبات اللوجستيات — *table* (الحالة ☐ جديد/قيد التنفيذ/مكتمل/متأخر/ملغى) 3. جاهزية الفعاليات — *table*
4. إدارة المخزون — *table* 5. النقل والتنقل — *table* 6. الصيانة والأعطال — *table*
7. دعم التنفيذ (4 أسئلة: ثلاثة نعم/لا + الاحتياج المتكرر) 8. مؤشرات الأداء 9. الخطة القادمة

## 3. الإدارة التنفيذية
هدف: توثيق ما تم تنفيذه فعلياً من المشاريع والفعاليات والأنشطة المخططة، وقياس الفرق بين المخطط والمنفذ.
1. ربط التنفيذ بالخطة 2. قبل التنفيذ (قائمة تحقق) 3. أثناء التنفيذ 4. سجل المهام التنفيذية — *table* (الحالة ☐ مكتملة/جزئياً/لم تنفذ/مؤجلة)
5. المستفيدون 6. الموارد البشرية التنفيذية 7. المشاكل والتغييرات — *two tables* (نوع المشكلة ☐ لوجستية/بشرية/تقنية/تنظيمية/مالية/خارجية)
8. التنسيق مع الأقسام (☐ متوفر/جزئي/غير متوفر لكل قسم) 9. تقييم التنفيذ (تقييم من 5 لسبعة معايير)
10. مؤشرات الأداء 11. المرفقات

## 4. الإدارة المالية
هدف: ضبط الإيرادات والمصروفات والميزانيات والالتزامات والمستندات المالية وإظهار الوضع المالي بوضوح لمجلس الإدارة.
1. بيانات التقرير (+ العملة) 2. الإيرادات — *table* 3. المصروفات — *table* 4. الميزانية مقابل الصرف — *table*
5. الالتزامات والمستحقات — *table* 6. الرصيد والحركة 7. المستندات المالية (☐ مكتمل/ناقص/بانتظار الاستلام)
8. الرقابة المالية 9. مؤشرات الأداء 10. الخطة القادمة

## 5. التقانة وإدارة البيانات

1. بيانات التقرير 2. الأنظمة والمنصات — *table* 3. طلبات الدعم التقني — *table* 4. الحسابات والصلاحيات — *table*

## 6. الموارد البشرية
هدف: إدارة دورة حياة العضو، الاستقطاب، الحضور والمشاركة، تقييم الأداء، التدريب، الحالات الإدارية، ورضا الأعضاء.
1. بيانات التقرير 2. القوة البشرية (+ جدول التوزيع حسب القسم والدور) 3. الاستقطاب والمقابلات 4. العضوية والإجراءات

7. التدريب والتطوير — *table* 8. الحالات الإدارية 9. رضا الأعضاء 10. مؤشرات الأداء 11. الخطة القادمة
